三、反思：完成本次作业后，你对 AI 工具的能力边界有什么新的认识？

--------------------------------------------------------------------------------------------------------------------
	我认为，AI虽然能根据指令直接生成代码，但是会有以下几个问题：
1.如果给的指令（简单的自然语言）不够明确，AI可能会理解错误，导致实际功能与原来的有偏差：
	如：我让AI进行需求预测功能实现时，AI直接输出了一月份订单量，而没有进行任何实际运算，
是一份伪功能，需要我仔细阐明这个功能到底要实现什么要求，每一步逻辑分析要怎么做，AI才能正确生成内容；
2.AI生成代码的时候，尽管我每次都会复制基本要求，但是AI仍然会出现AI幻觉，遗漏或者误解部分功能要求，
导致最后生成的代码不完全符合小功能要求；
3.要实现一个大的系统功能的时候，AI能根据用户详细的指令生成对应的代码，
但是这其中需要用户清楚地知道整个任务要拆解成多少个小任务，
了解每个小任务的分析策略、判断逻辑、执行步骤是什么，以及有强大的代码审查能力，
才能让AI生成正确的代码，并且将每部分小功能整合起来，否则无法真正实现系统功能，
所以编程中最需要的还是我们的算法设计、整体架构、代码阅读审查能力，AI更大程度上是起到一个辅助作用。
--------------------------------------------------------------------------------------------------------------------
	但是AI也存在一些优点：
1.当遇到看不懂的报错的时候，可以直接复制报错询问AI而不需要辛苦地查询报错对应含义，节约debug时间；
2.将功能拆解后让AI生成时，AI还会额外考虑一些自己本身没有考虑到的问题，让程序更严谨；
3.AI生成的代码更简洁，可读性较高，人工编写的代码可能存在部分内容冗余，逻辑性不强等问题。
